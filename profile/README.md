# TechLeads.fyi

We help you see what websites are built with — and find companies that use the tech you care about.

Track thousands of technologies across hundreds of millions of sites. Use it for sales, research, or your own products.

## What you can use

- **Website** — search, lookup, and lead lists at [techleads.fyi](https://techleads.fyi)
- **REST API** — look up any domain’s tech stack · [docs](https://techleads.fyi/developers)
- **CLI (`tlf`)** — scriptable lookups from your terminal
- **npm** — SDK + CLI as [`@techleads.fyi/api`](https://www.npmjs.com/package/@techleads.fyi/api) · [source](https://github.com/techleads-fyi/api)
- **MCP** — plug TechLeads into AI assistants · [docs](https://techleads.fyi/developers?tab=mcp)

```bash
npm i -g @techleads.fyi/api
tlf login
tlf -d example.com
```
